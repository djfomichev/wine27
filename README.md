# Белый мыс · Карта года2027

Интерактивная управленческая карта: нагрузка по12месяцам, события, постоянная программа, праздники, проекты и локальный сценарий команды.

Исходная программа: раскадровка v10 от 03.11.2026. Музыкальная конференция исключена из2027. Сезонные окна и масштабы отмечены как предварительные.

## Публикация
Файлы этой папки разместить в корне репозитория djfomichev/wine27. GitHub: Settings → Pages → Source: Deploy from a branch → main → /(root) → Save. Ожидаемый адрес: https://djfomichev.github.io/wine27/

## Просмотр и данные
index.html открывает карту. Все шрифты, стили и данные находятся в этой папке; сборка не требуется. Расчёты сохраняются в браузере, JSON можно скачать и загрузить. При переходе с другого адреса локальные сценарии автоматически не переносятся: сначала скачайте их на старой странице, затем загрузите на новой. Общей базы и совместного редактирования нет.


## Автоматическое обновление
После правок запускается python3 scripts/stamp-version.py и все изменения публикуются вместе. Открытая вкладка проверяет новую версию каждые15секунд и обновляется после завершения публикации GitHub Pages. Во время ввода обновление откладывается; выбранный месяц, фильтры и сохранённые расчёты остаются. Для первого включения этой функции на старой вкладке потребуется1ручное обновление.


## Рабочий план и мобильная версия
Последний прямой запрос: перенести правки v10 на сайт, сохранить рабочие даты, разложить всю программу по срокам, сделать интерфейс крупнее и адаптировать для телефона. Экранные слайды для персонала от этого не получают даты.

В основном режиме карта читается крупно; «Весь год» даёт компактный обзор. На телефоне есть нижняя навигация, быстрый переход к месяцу и список событий с датами вместо узкой недельной сетки. Шрифты и цвета брендбука сохранены.

Экспертный портфель содержит 15 родительских проектов и 1 дочернюю сессию. Предлагаемые сроки программной дирекции отделены от ранее принятых решений. Партнёры, бюджеты и готовность объектов требуют подтверждения. Все существовавшие идентификаторы сохранены; премия остаётся внутри Винной недели.


Файлы программы: data.js хранит исходную раскадровку и рабочие события, expert-data.js раскрывает портфель Соловьёва, planning-data.js хранит предлагаемые сроки, подготовку, вложенные форматы и регулярный ритм. plan.js связывает эти данные. Совместная подготовка нескольких проектов — 1 этап; резиденции и вложенные программы занимают существующие слоты.

Новые рабочие окна: выставки 5–14 февраля и 4–14 ноября; фестиваль сыров 27–28 марта; «Этюды» 3–5 сентября. Они требуют согласования. Игристые не получили первого года. Неизвестным открытиям назначены контрольные этапы, а не обещанный день открытия.
