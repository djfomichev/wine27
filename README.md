# Белый мыс · 2027

2 версии программы в одном репозитории:

- https://wine27.ru/ — карта для руководства и коллег: события, даты, темы месяцев, новые проекты и регулярная программа.
- https://wine27.ru/work/ — рабочая программа: подготовка, вопросы, варианты, расписания и расчёт команды. Страница доступна по ссылке; авторизации нет.

## Данные

Исходные данные находятся в work/data.js, work/expert-data.js и work/planning-data.js. Скрипт scripts/build-public.py формирует из них данные основной страницы, сохраняя идентификаторы, даты и проекты. Чистовые формулировки находятся в этом скрипте; при изменении содержания проекта нужно обновить и их. Не редактируйте сгенерированные данные в корне вручную.

Общие интерфейс, стили, шрифты и логотип используются обеими версиями. Программа для персонала в текстовой раскадровке остаётся без календарных дат; карта сайта содержит даты.

## Публикация

Запустите проверки из AGENTS.md. scripts/stamp-version.py выпускает обе страницы с единым номером версии. GitHub Pages публикует main из корня репозитория. Проверьте site-version.json на основном адресе и /work/ после публикации.

Открытые вкладки проверяют обновления каждые 15 секунд. Переходы, фильтры и прокрутка сохраняются; обновление откладывается во время ввода. Расчёт команды хранится в браузере под прежним ключом и доступен в рабочей версии. Его можно скачать и загрузить как JSON; совместное редактирование не подключено.

## Логика месяца

События по датам показывают отдельные фестивали, уикенды и праздники. Регулярная программа раскрывает повторяющиеся форматы: содержание, место и ритм. Сервисы города показываются отдельно. В рабочей версии дополнительно видны проекты перед запуском, работа команды, этапы подготовки и калькулятор ресурса. Резиденции и вложенные программы не создают повторный общий продакшен.
